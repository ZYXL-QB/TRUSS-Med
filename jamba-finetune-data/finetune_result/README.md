# 历史微调记录 / Fine-tuning records

此目录归档各组的 LoRA 配置、分词器文件和训练记录。原始归档中的 LoRA 权重同步不完整，目前缺少可加载的适配器权重。要运行微调后推理，请按[项目 README 第 7 步](../../README.md#7-lora-微调与推理)生成适配器。

This directory archives LoRA configurations, tokenizer files, and training records. The available copies of the adapter weights are incomplete. To run inference with a fine-tuned adapter, generate one by following [Section 7](../../README_en.md#7-lora-fine-tuning-and-inference).
